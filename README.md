# VortexRecon CTI Lab

This repository demonstrates foundational Cyber Threat Intelligence (CTI) skills with an emphasis on:
- Structured threat reporting
- Indicator handling and enrichment
- Defender-focused analysis
- Automation mindset using Python

## Contents
- `reports/` – Finished CTI briefs written for SOC and security leadership
- `scripts/` – Simple Python utilities for IOC parsing and handling
- `notebooks/` – Demonstrations of enrichment logic and analysis workflows

## Focus
This project prioritizes clarity, practicality, and decision-support over exploit development.

## Roadmap
- Additional ransomware and malware briefs
- IOC enrichment automation
- Integration with open-source intelligence feeds
